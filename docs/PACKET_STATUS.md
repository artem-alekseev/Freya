# Packet Status

Критерий:

- `готовые` — opcode есть в `cmd/gameserver/packet/const.go` и у него есть обработчик.
- `частично готовые` — opcode зарегистрирован, но handler `nil` или это только уведомление без локальной логики.
- `не готовые` — opcode есть в `WorldSvr/ProtodefEx.h`, но отсутствует в текущем `const.go`.
