# Client → server packet status

В документе оставлены только пакеты, которые инициируются клиентом:

- `CSC_*` — client/server commands;
- `REQ_*` — client requests.

Исключены `NFY_*`, `ITC_*`, `RES_*`, `C2C_*`, `EMS_*`, `IPC_*` и прочие
серверные или внутренние сообщения.

Источник списка opcode: `WorldSvr/ProtodefEx.h`.

Критерий готовности: opcode присутствует в `cmd/gameserver/packet/const.go` и
зарегистрирован в `cmd/gameserver/packet/packet.go` с ненулевым обработчиком.

Всего client → server пакетов: `342`
Готовые: `88`
Не готовые: `254`
